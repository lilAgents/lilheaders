# lilHeaders

Security Headers Checker

Scan any site's HTTP response headers and grade its security posture: HSTS, CSP, X-Frame-Options, and the rest, explained in plain English.

Part of [Hot App Summer](https://hotappsummer.netlify.app) by [lilAgents](https://lilagents.com): one small, useful web tool shipped every day through June.

## Run it locally

This is an [Astro](https://astro.build) site.

```bash
pnpm install
pnpm dev
```

To build for production:

```bash
pnpm build
```
